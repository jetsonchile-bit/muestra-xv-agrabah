# Muestra — invitación digital de XV años

Demostración navegable de una invitación de XV años con temática de "las mil y una noches".
Todos los datos son inventados: nombre, salón, dirección y cuenta bancaria no corresponden a nadie.

- El cielo del desierto avanza de tarde a noche a medida que se hace scroll.
- La lámpara del arco abre el selector de fotos: la imagen queda en la portada.
- Confirmación, muro de mensajes, galería y copia de datos funcionan en el propio navegador,
  sin enviar nada a ningún servidor. La versión final usa Supabase.
- La música es un arpegio en escala *hijaz* sintetizado con Web Audio; no hay archivo ni licencia de por medio.

Sin personajes, arte ni tipografías de terceros.
